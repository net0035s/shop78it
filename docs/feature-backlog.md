# ฟีเจอร์ใหม่ที่แยกไว้ทำภายหลัง

รายการเดิมจากงานแก้ 26 ประเด็น อัปเดต 11 ตุลาคม 2026: FAQ ทั่วไป หน้าตรวจความพร้อม งานค้าง บันทึกคืนเต็มยอด และการแก้ข้อความรีวิว/การส่งทันที ได้ทำในรอบเตรียมเปิดร้านแล้ว รายการด้านล่างระบุส่วนที่ยังเหลือ

1. หน้าสินค้าลิงก์ถาวร พร้อม sitemap, robots และข้อมูลสินค้า structured data
2. เวลาจัดส่ง manual และเงื่อนไขประกันรายสินค้าที่เจ้าของร้านรับรอง (FAQ ทั่วไปทำแล้ว ไม่สมมติเวลาดำเนินงานให้ร้าน)
3. คืนเงินบางส่วน/ยอดขาด/ยอดเกิน และขั้นตอนอนุมัติที่เชื่อมผู้ให้บริการจริง (บันทึกคืนเต็มยอดที่ทำภายนอกพร้อม audit ทำแล้ว)
4. ตรวจคีย์ซ้ำและ preview ก่อน import; จัดส่งบางส่วนและติดตามรายการคงค้างแบบละเอียด
5. ปิดขาย/ซ่อนสินค้าแทนลบประวัติ และจัดการอายุคีย์/การรับประกัน
6. ประวัติการซื้อข้ามอุปกรณ์ในบัญชีลูกค้า โดยรักษาการยืนยันเจ้าของออเดอร์
7. ปุ่มถอนความยินยอมคุกกี้ และหยุดเครื่องมือติดตามที่เริ่มทำงานแล้ว
8. ปรับ keyboard navigation, focus trap/คืน focus และ Escape ใน dialog พร้อมทดสอบการเข้าถึงบนมือถือ
9. บริการติดตามข้อผิดพลาดและแจ้งเตือนภายนอกแบบต่อเนื่อง (หลังบ้านแสดงงานรับเงิน/คิวค้างและการส่งหมด retry ทำแล้ว)
10. กำหนดอายุเก็บข้อมูล/กระบวนการขอลบข้อมูล และตรวจความสอดคล้องของนโยบายกับการให้บริการจริง
11. ตรวจไฟล์ prisma/dev.db ที่ติดตามใน repository ก่อนเผยแพร่ repository โดยไม่สมมติว่าข้อมูลข้างในเป็นข้อมูลจำลอง
12. ระบบรีวิวจริงและหลักฐานรับรองสินค้า (เอา 500+ รีวิว/ปลอดภัย 100%/ส่งทันทีทุกชนิดที่ไม่มีหลักฐานออกจากหน้าแรกและปรับข้อความหลักแล้ว)

การเปิดรับเงินจริง การเปลี่ยนกุญแจ และการ deploy เป็นงานปฏิบัติการถัดไปตามแผนย้ายข้อมูล ไม่ใช่ส่วนที่ดำเนินการในรอบนี้
